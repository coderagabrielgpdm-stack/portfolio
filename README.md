# Gabriel G. Codera - Personal Portfolio

A modern, professional, and fully responsive portfolio website built with **React**, **Tailwind CSS**, and **Framer Motion**.

## 🎨 Features

- ✨ **Modern UI Design** - Dark mode with glassmorphism effects and gradient accents
- 🎬 **Smooth Animations** - Scroll-triggered animations and interactive hover effects
- 📱 **Fully Responsive** - Mobile-first design that works on all devices
- ⚡ **High Performance** - Optimized with Vite for fast loading
- 🎯 **Interactive Components** - Typing animation, smooth scrolling, scroll progress bar
- 🚀 **Modern Tech Stack** - React 18, Tailwind CSS, Framer Motion

## 📋 Sections

1. **Hero** - Eye-catching introduction with typing animation and CTA buttons
2. **About** - Educational background and personality traits with stat cards
3. **Skills** - Technical skills, personal qualities, and tech stack
4. **Education** - Animated timeline of educational journey
5. **Projects** - Featured project and project grid with live demos
6. **Seminars** - Attended seminars and participation history
7. **Contact** - Contact information and message form

## 🛠 Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: React Icons
- **Intersection Observer**: For scroll animations

## 📦 Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🚀 Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Start the dev server: `npm run dev`
4. Open [http://localhost:3000](http://localhost:3000) in your browser

## 📝 Customization

### Update Personal Information
- Edit `src/components/Hero.jsx` for name and subtitle
- Update social links in various sections
- Modify project links in `src/components/Projects.jsx`

### Change Colors
- Edit color values in `tailwind.config.js`
- Update color references in component files

### Add New Projects
- Add project data to the `projects` array in `src/components/Projects.jsx`
